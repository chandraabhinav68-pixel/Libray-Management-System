Key Features

Everything a modern library needs, built in Java Swing

📖

Catalog Management

Add, edit, delete and search Physical Books and E-Books with full CRUD operations and real-time search filtering.

👤

User Directory

Register Students (3 books / 14 days) and Faculty members (10 books / 30 days) with role-based borrowing policies.

🔄

Issue & Return

Process book issues and returns with automatic due date tracking and polymorphic overdue fine calculations.

🧵

Multithreading

Background fine sweep (Runnable) and catalog backup export (Callable<Boolean>) run asynchronously without freezing the UI.

🗄️

SQLite Database

All data persisted in an embedded SQLite database via JDBC PreparedStatements with SQL injection protection.

📊

Analytics Dashboard

Real-time metrics, thread task console logs, and live inventory / user / fine summaries on the analytics tab.

How to Run

Get started in under 60 seconds

1

Clone Repository

git clone https://github.com/chandraabhinav68-pixel/
Libray-Management-System.git

Clone the project from GitHub to your local machine

2

Build the Project

cd Libray-Management-System
build.bat

Double-click build.bat to compile all Java source files into the bin/ directory

3

Launch the App

run.bat

Double-click run.bat to launch the Swing GUI. The SQLite database is created automatically!

📋 Requirements

  • ✅ JDK 17 or JDK 21+ installed
  • ✅ Windows OS (for .bat files) — or use manual javac/java commands on Linux/Mac
  • ✅ SQLite JDBC driver already included in lib/ — no installation needed

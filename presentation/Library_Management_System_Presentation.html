Library Management System

Java GUI Desktop Application | OOP Design, SQLite JDBC, Multithreading & DAO Architecture

Project Presentation & Architecture Overview

1. Executive Project Summary

Key System Features

  • Complete CRUD Inventory: Books & E-Books management with custom properties.
  • User Directory: Student & Faculty profile registration with role-based policies.
  • Issue & Return Processing: Real-time book issue, due-date calculation, and fine handling.
  • Multithreading Console: Asynchronous background fine calculation sweeps & catalog CSV backup exports.

Technical Architecture

  • GUI Framework: Java Swing (EDT event dispatching, JTabbedPane, JTable, RowSorter)
  • Database: SQLite JDBC Driver (Zero configuration embedded DB)
  • Design Patterns: Singleton (DatabaseManager), Generic DAO Repository Pattern, Model-View-Service Separation

3. Database Connectivity (JDBC) & DAO Architecture

DAO Repository Design

Data Access Object (DAO) classes separate SQL query mechanics from business logic:

  • BookDAO: Maps JDBC ResultSet to Book and EBook domain models.
  • UserDAO: Persists and fetches StudentUser and FacultyUser records.
  • TransactionDAO: Manages issue/return records and fine status.

PreparedStatements & Security

4. Multithreading & Synchronization

Concurrent thread execution for background tasks and thread safety:

Background Worker Tasks

  • Runnable Thread (FineCalculationTask): Periodically audits active loans, computes overdue charges, and updates database records asynchronously.
  • Callable Thread (BackupTask): Exports catalog data to CSV format using thread pool futures without freezing the UI.

Thread Synchronization & Safety

Uses ReentrantLock in LibraryService to prevent double-booking race conditions during simultaneous book issue requests:

private final ReentrantLock transactionLock = new ReentrantLock(); public Transaction issueBook(String uid, String iid) { transactionLock.lock(); try { // Safe concurrent inventory check & issue } finally { transactionLock.unlock(); } }
